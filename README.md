# oft_bio_maze
この度は、最適採餌理論に関する実験のために作成された、自作ゲームである今作を手に取ってくださりありがとうございます。プレイすることによる、サンプルのご提供をよろしくお願いいたします。

【概要】
最適採餌理論(OFT)に基づいた最適行動から、人間は、自身の周辺にあるブラックボックスを開けたいという興味などの心的要因などから、どこまで離れた行動をとるのか。また、どのような行動パターンがみられやすいのかを計出するための自作の迷路型ゲームです。

【遊び方】
  モード選択
    上下キーやクリック、タップで選択してください
  操作方法
    上下左右キーかwasdキーで移動できます。
      移動時にはダメージを受けます。
      モードによっては静止している状態でもダメージを受け続けます。
    enterキーでマップを変更できます。
      マップ変更時には10、25、50ダメージをそれぞれ一定の確率で受けます。
      マップ変更後のフィールド内のエサの数は20個、40個、60個からそれぞれ一定の確率で選ばれます。

  遊び方
    プレイヤーはフィールド内の移動やフィールド間の移動を通じて最終的なHPが最も高くなるように60秒間動いてください。
    HPはフィールド上に落ちているエサを食べることで回復します。
    HPの上限は300です。0となるとゲームオーバーでスコアは0となります。
